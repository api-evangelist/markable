# Markable

> Markable (markable.ai) is a creator-monetization platform that turns social posts into affiliate
> revenue — smart deeplinks across Amazon, Target and Walmart, a shop-in-bio storefront, Instagram
> auto-DM replies, AI-generated collages and captions, viral-product discovery and performance
> analytics. Markable also published an earlier developer product, the **Markable Lens API** — a
> visual-search platform for finding products and styles inside images and video against indexed
> catalogs. The Lens API reference is still publicly served, but the API hosts it documents were
> not reachable when last probed (2026-08-13).

This file was generated by API Evangelist from Markable's public surface. Markable does not publish
an llms.txt of its own (https://www.markable.ai/llms.txt returned 404 on 2026-08-13).

## Status at a glance

- No OpenAPI, AsyncAPI, GraphQL, MCP server or A2A agent card is published (contract discovery run
  against www.markable.ai, docs-dev.markable.ai, app-prod.markable.ai and catalog.markable.ai).
- No /.well-known/ discovery documents on any host.
- No first-party SDK on npm, PyPI or any other registry.
- Lens API access is gated: "To be able to use/access this API you will need to be a verified
  developer, please contact us to get started."
- Runtime: auth.markable.ai and video.markable.ai do not resolve; catalog.markable.ai answers 404
  from an unrouted ingress; https://markable.ai/signup (the documented developer signup) is 404.

## APIs

- [Markable Lens API](https://docs-dev.markable.ai/): visual product and style search across images
  and video, plus catalog and catalog-item management and a category/attribute taxonomy.
  Documented hosts: `auth.markable.ai` (tokens), `catalog.markable.ai` (catalogs, items, image and
  style search, taxonomy), `video.markable.ai` (video search).

## Documented operations

- `POST https://auth.markable.ai/auth/user/authorize` — exchange email + password for a user access token
- `GET  https://auth.markable.ai/auth/users` — get the user record and its default client
- `POST https://auth.markable.ai/auth/client/authorize` — exchange client credentials for the client access token used on every Lens call
- `POST https://catalog.markable.ai/catalogs` — create a catalog (`product` or `style` schema)
- `GET  https://catalog.markable.ai/catalogs` — list catalogs (`limit` default 50, `skip`)
- `GET  https://catalog.markable.ai/catalogs/public` — list public catalogs
- `GET  https://catalog.markable.ai/catalogs/:catalogId` — get a catalog
- `PUT  https://catalog.markable.ai/catalogs/:catalogId` — update a catalog
- `DELETE https://catalog.markable.ai/catalogs/:catalogId` — delete a catalog
- `GET  https://catalog.markable.ai/catalogs/:catalogId/stats` — catalog statistics
- `POST https://catalog.markable.ai/catalogs/:catalogId/items` — create a catalog item
- `GET  https://catalog.markable.ai/catalogs/:catalogId/items` — list catalog items (`limit` default 20, `skip`)
- `GET  https://catalog.markable.ai/catalogs/:catalogId/items/:itemId` — get a catalog item
- `PUT  https://catalog.markable.ai/catalogs/:catalogId/items/:itemId` — update a catalog item
- `DELETE https://catalog.markable.ai/catalogs/:catalogId/items/:itemId` — delete a catalog item
- `POST https://catalog.markable.ai/image/search` — product search in an image
- `POST https://catalog.markable.ai/image/search/style` — "how to wear it" style search in an image
- `POST https://video.markable.ai/video/search` — video search (`page`, `pageLimit`)
- `GET  https://catalog.markable.ai/category` — supported categories
- `POST https://catalog.markable.ai/category` — category lookup
- `GET  https://catalog.markable.ai/attributes` — supported attributes

## Conventions

- Auth: HTTP Bearer (RFC 6750). Two stages — user access token, then client access token.
- Envelope: requests and successful responses wrap payloads in a top-level `data` object; objects
  carry `_type` and `_id`.
- Errors: JSON:API error objects in a top-level `errors` array (title, id, status, code, detail,
  links, source, meta).
- Pagination: `limit`/`skip` on catalog and item lists; `page`/`pageLimit` on video search.
- Rate limit: 25 requests/minute per client. No rate-limit response headers are documented; 429 on
  exhaustion.
- Versioning: none implemented — the API is documented as private beta.
- Idempotency: not supported / not documented.
- Image constraints: .jpg/.jpeg/.png, 100–6000 px, max 10485760 bytes, aspect ratio 0.4–2.5.
